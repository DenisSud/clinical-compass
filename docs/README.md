## Принцип

- `case/` — **что требуют**. Меняется только если организаторы уточнят.
- `domain/` — **что в медицине и праве**. Меняется по мере проверки фактов.
- `team/` — **что решили люди**. Единственное место, где живут незакрытые вопросы.
- `reference/` — **что уже сделано**. Факты о коде, а не мнения.

Решения, которые меняют архитектуру, фиксируются отдельно в `docs/decisions/`
(см. ADR-шаблон там же).

## Язык

Документы в `case/`, `domain/`, `team/` — на русском: они переиспользуются в сдаче.
Технические документы и код — на английском.
