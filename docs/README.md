## Принцип

- `case/` — **что требуют**. Меняется только если организаторы уточнят.
- `domain/` — **что в медицине и праве**. Меняется по мере проверки фактов.
- `team/` — **что решили люди**. Единственное место с незакрытыми вопросами.
- `reference/` — **что уже сделано**. Факты о коде, а не мнения.
- `decisions/` — **что выбрали и чем заплатили**. Один файл на решение.

Принятые решения: `0001` только локальные модели · `0002` Python сейчас,
pi-durable позже · `0003` правила авторитетны · `0004` запись на приём — заглушка.

## Язык

`case/`, `domain/`, `team/`, `decisions/` — на русском: переиспользуются в сдаче.
`architecture.md`, код и комментарии — на английском.
