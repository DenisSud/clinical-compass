## Принцип

- `case/` — **что требуют**. Меняется, только если организаторы уточнят.
- `domain/` — **что в медицине и праве**. Меняется по мере проверки фактов.
- `team/` — **что решили люди**. Единственное место с незакрытыми вопросами.
- `reference/` — **что уже сделано**. Факты о коде, а не мнения.
- `decisions.md` — **что выбрали и чем заплатили**.

## Язык

`case/`, `domain/`, `team/` — по-русски: переиспользуются в сдаче.
`architecture.md`, `code-tour.md`, `decisions.md` — тоже по-русски: их читают те же люди. По-английски — код, докстринги, комментарии и коммиты.
