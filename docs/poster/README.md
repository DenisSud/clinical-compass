# Постер А1 (594×842 мм, PDF)

Черновик постера о прототипе. Источник содержания — этот каталог, а не отдельный
текстовый файл: правки вносятся в данные в начале `build_poster.py`
(`SECTION_1`…`SECTION_5`, `FUNCTIONS`, `TEAM`, `THANKS`), а не в верстку.

## Сборка

Нужны ReportLab и шрифт с кириллицей (DejaVu Sans Regular + Bold):

```sh
python3 -m venv .venv && .venv/bin/pip install reportlab
.venv/bin/python docs/poster/build_poster.py --out poster-a1.pdf --fonts /path/to/dejavu
```

`--fonts` — каталог с `DejaVuSans.ttf` и `DejaVuSans-Bold.ttf` (оба файла есть в пакете
`dejavu-fonts-ttf`). Скрипт печатает отчёт: свободное место по колонкам в мм и число
элементов, не влезших в колонки (`leftover_flowables` должен быть 0).

## Порядок блоков — как в требованиях

| # | Блок требований | Где на постере |
| --- | --- | --- |
| 1 | Идея проекта / решения кейса | левая колонка, §1 |
| 2 | Что удалось сделать — прототип | средняя колонка, §2 |
| 3 | Результаты испытания — метрики | правая колонка, §3 |
| 4 | Дальнейшие предложения и планы | правая колонка, §4 |
| 5 | Команда, благодарности, QR | нижняя полоса, §5 |

Полоса «Функции кейса: что покрыто прототипом сегодня» — не отдельный пункт: она
показывает восемь функций кейса и стоит между телом постера и нижней полосой.

## Откуда цифры в блоке 3

Все они измерены скриптом `scripts/metrics/run.mjs` и записаны в `docs/metrics.md`
(`docs/metrics-results.json` — сырые числа). Пересобрать:

```sh
node scripts/metrics/run.mjs          # поднимет приложение и снимет те же метрики
```

Ничего не вписано руками: если число поменялось, его надо менять в отчёте, а потом в
`SECTION_4` этого скрипта.

- Слой решений против модели — `scripts/metrics/decisions.ts`, отчёт `docs/decisions.md`
  (сырые числа в `docs/decisions-results.json`): 24 состояния пациента, правила шкалы как
  эталон, d1:latest и qwen3.5:4b через локальный ollama. Пересобрать:

  ```sh
  node --import tsx scripts/metrics/decisions.ts --d1 d1:latest --llm qwen3.5:4b
  ```

- 40 HTTP-маршрутов — `grep -c "app\.\(get\|post\|patch\|put\|delete\)" server/routes/*.ts`.
- 10 таблиц — `sqliteTable(` в `server/db/schema.ts`.
- 130 тестов в 15 наборах — прогон `vitest run`, не счёт по коду.
- PHQ-9: 9 пунктов, 5 диапазонов, критический пункт `q9` — `server/instruments/phq-9.json`.
- Корпус знаний: один ОХЛП («АВИАНДР»), клинрекомендаций нет — `server/knowledge/`.
- Модель не реализована: в `server/ai/clinical-assistant.ts` только тип-порт.

## Известные отклонения

- Размер: 594×842 мм, как в требованиях. По ГОСТ А1 — 594×841 мм; если приёмка
  строгая, высоту надо уменьшить на 1 мм (`PAGE_H` в скрипте).
- Палитры бренда нет, поэтому постер чёрно-серый: иерархия размером, весом и линиями,
  как и требует `DESIGN.md`.
