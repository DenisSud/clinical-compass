# ADR-0001: Только локальные модели

Дата: 2026-10-20
Статус: принято

## Контекст

Кейс требует соблюдения конфиденциальности и соответствия законодательству РФ.
Медицинские данные — специальная категория персональных данных (152-ФЗ). В чате
команды прозвучал вопрос, не надо ли сразу использовать локальные модели вместо
внешнего API.

## Решение

Никакого сетевого выхода к моделям. Всё через Ollama на localhost. Ни один
символ пациента не покидает хост.

Роли моделей:
- рассуждение — `qwen3.5:4b` сейчас, `bonsai-2:27b` когда установится;
- решения — `d1` (LFM2, 2.7B, `capabilities: ["decision"]`);
- эмбеддинги — `nomic-embed-text-v2-moe`, 768 измерений.

Один источник правды — `compass_ai.models.ModelRoles`, переопределяется
переменными окружения `COMPASS_MODEL_*`.

## Последствия

Проще: заявление о конфиденциальности становится проверяемым («вот `ss -tp`, вот
конфиг, наружу ничего нет»), а не обещанием.

Дороже: качество рассуждения ограничено 4B-моделью, пока не установится Bonsai.
Промпты придётся писать под слабую модель: короткие, со схемой ответа.

Нельзя: полагаться на «модель сама знает». Только найденные фрагменты.
