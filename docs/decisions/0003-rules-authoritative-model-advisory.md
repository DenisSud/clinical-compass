# ADR-0003: Правила авторитетны, модель только советует

Дата: 2026-10-20
Статус: принято

## Контекст

Обязательное условие кейса: решение не выполняет клинических действий
самостоятельно. `d1` даёт уверенность (мы видели 92%, 93%, 98%), и её легко
принять за вероятность. Это 2.7B классификатор: он ошибается на отрицании,
сарказме и разговорном русском.

## Решение

Инвариант в коде (`compass_ai.triage.merge`): **модель может только повысить
внимание, понизить — никогда.**

- Находки из шкал (`Score.findings`) — `authoritative=True`.
- Ответы `d1` — `authoritative=False`, ранг ниже, уверенность приложена для
  человека.
- Врач видит, что авторитетно, а что подозрение. Это различие — часть UI, а не
  деталь реализации.

## Последствия

Проще: любая клиническая претензия проверяема — «это правило шкалы, вот пункт,
вот источник».

Дороже: модель не может снять ложную тревогу. Ложноположительные срабатывания
будут, и врач будет их закрывать.

Нельзя: использовать уверенность модели как порог для клинического действия.
