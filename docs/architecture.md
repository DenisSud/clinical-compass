# Архитектура

Состояние на 20.10.2026. Собрано из решений A1–A5 и ответов на раунд 1.

## Форма

```
┌──────────────────────────────────────────────────────────────┐
│  apps/api  — клиническое ядро (Python, Django)                │
│  роли · связь врач-пациент · шкалы · правила · аудит · план   │
│  Детерминированное. Не зависит от модели.                     │
└───────────────┬──────────────────────────────────────────────┘
                │ импорт (не сеть)
┌───────────────▼──────────────────────────────────────────────┐
│  compass/ai — граница моделей                        │
│  Assistant (Protocol)                                         │
│    ├─ triage      d1: да/нет, выбор, уровень срочности        │
│    ├─ retrieval   BM25 + векторы по фрагментам                │
│    ├─ drafting    черновик строго по найденным фрагментам     │
│    └─ extract     структурированные поля из выписки           │
└───────────────┬──────────────────────────────────────────────┘
                │ HTTP / CLI
┌───────────────▼──────────────────────────────────────────────┐
│  Ollama на localhost                                          │
│  qwen3.5:4b (рассуждение) · d1 (решения) · nomic (эмбеддинги) │
└──────────────────────────────────────────────────────────────┘
```

## Почему `compass/` — это Python-пакеты, а не микросервисы

Решение A2: сейчас микросервисы не нужны. `apps/api` импортирует `compass.*`
как обычные пакеты. Всё это один процесс, один venv, один деплой.

Когда появится потребность в одном долгоживущем агенте с состоянием, к которому
врач обращается разговором, — это станет второй реализацией `Assistant` поверх
pi-durable сервиса. Клиническое приложение не изменится. Ради этого Protocol и
существует: `apps/api` не импортирует `Ollama` напрямую.

## Три слоя, три разных гарантии

| Слой | Что делает | Гарантия | Может ли отказать |
|---|---|---|---|
| **Детерминированный** | Подсчёт шкал, противопоказания, алерты, аудит | Всегда одинаковый результат | Нет (нет внешних зависимостей) |
| **Извлекающий** | d1 классифицирует текст: суицидальные мысли, НЯ, приверженность, срочность | Оценка + уверенность | Да, деградирует в «нет сигнала» |
| **Генерирующий** | RAG-черновик рекомендации со ссылками | Каждое утверждение с цитатой или отказ | Да, отказывает целиком |

Правило, которое цементирует всё: **модель может только повысить внимание,
понизить — никогда.** Оценка PHQ-9, где пункт 9 выше нуля, авторитетна.
Уверенность d1 = 93% — нет.

## Границы цитирования

`drafting.draft()` отвергает черновик, если модель сослалась на фрагмент,
которого ей не давали, или не сослалась ни на что. Это не паранойя — это
техническое исполнение критерия «научная обоснованность». Рекомендация, которую
врач не может проследить до источника, хуже отсутствия рекомендации.

## Карта модулей

| Путь | Ответственность | Зависит от |
|---|---|---|
| `compass/instruments` | Определения шкал (JSON), подсчёт, сигналы безопасности | ничего (stdlib) |
| `compass/knowledge` | Корпус: бандлы, фрагменты, точные смещения | `compass.knowledge.Passage` |
| `compass/ai` | Модельная граница, триаж, поиск, черновики | `httpx`, Ollama |
| `apps/api` | HTTP, роли, БД, аудит, шаблоны | Django + все три |

`instruments` не зависит ни от чего. Это сделано намеренно: подсчёт шкал должен
работать в тесте без модели, без БД и без сети.

## Что измеряется (решение A5)

| Метрика кейса | Как доказываем |
|---|---|
| **2** — извлечение из выписок разных шаблонов | Пакет разноформатных выписок + прогон `extract()` + подсчёт точности по полям |
| **4** — эргономика | Число действий и секунды на один сценарий «пациент → врач → решение» |
| **7** — отказоустойчивость | RPO/RTO в README + тест «алерт не теряется при рестарте» |
| **10** — гибкость | `tests/test_instruments.py::test_a_new_scale_is_data_not_code` |
| **11** — гибкость данных | Схема БД + индексы в docs |

Метрики 1 (быстродействие) и 6 (нагрузка) не измеряем — заявляем как будущую
работу. Измерить их плохо хуже, чем не измерять.

## Известные долги

1. `apps/api` ещё не создан — см. `apps/README.md`, решение не принято.
2. `d1` доступен только через CLI (`ollama run d1 --ask`), HTTP-эндпоинта нет в
   Ollama 0.40.4. Мост в `ollama.decide()` — временный, помечен как таковой.
3. Векторы не персистентны: индекс пересобирается при старте. 132 фрагмента —
   это секунды. При росте корпуса понадобится кеш.
4. C-SSRS требует ветвления (идея → план → намерение → попытка). Схема
   определения это пока не выражает; текст шкалы в корпусе есть, движок — нет.
