# Авиандр® (маритупирдин) — препарат-якорь кейса

Источник: официальная инструкция по медицинскому применению, согласована 01.09.2025,
опубликована РЛС — https://www.rlsnet.ru/drugs/aviandr-89501
(дата обращения: 20.10.2026). Кейс требует опираться на действующую инструкцию из ГРЛС,
поэтому **перед сдачей перепроверить по grls.rosminzdrav.ru**.

## Идентификация

| Поле | Значение |
|---|---|
| Торговое наименование | АВИАНДР® |
| МНН | **маритупирдин** |
| Регистрационное удостоверение | ЛП-№(002445)-(РГ-RU) от 31.05.2023 |
| Держатель РУ | ООО «Авинейро», Химки, Московская обл. |
| Представитель | ООО «иФарма», Сколково |
| Форма выпуска | таблетки, п.п.о., 20 мг |
| ATX / группа | небензодиазепиновый анксиолитик, мультимодальный механизм |
| Отпуск | по рецепту |

Механизм: ингибирование 5-HT7 (очень высокое сродство), 5-HT6, 5-HT2A, 5-HT2C,
пресинаптических α2A/2B/2C и H1-рецепторов. Не ингибирует обратный захват
нейромедиаторов, не действует на ГАМК, не обладает антихолинергическим действием,
не удлиняет QT.

## Показания — только два, только взрослые 18+

1. **Лечение генерализованного тревожного расстройства (GAD).**
2. **Тревожные состояния после перенесённой COVID-19** у пациентов со стрессовой реакцией
   и нарушением адаптации, лёгкой и средней степени выраженности.

### Критическое следствие для продукта

**Авиандр не показан при депрессии.** Кейс говорит о «тревожно-депрессивной
симптоматике». Значит:

- Авиандр закрывает **тревожный** компонент.
- Депрессивный компонент требует другого препарата (СИОЗС/СИОЗСН и т.д.), который тоже
  должен быть в базе — иначе половина кейса не покрыта.
- Комбинация Авиандр + СИОЗС — это **серотонинергическая нагрузка**, и инструкция прямо
  предупреждает о риске серотонинового синдрома.

Это и есть естественный источник «предупреждений о безопасности терапии» (обязательное
условие 6) и «учёта рисков и нежелательных явлений» (функция 3). Работать не надо —
оно уже в инструкции.

## Противопоказания → готовые правила алертинга

Все проверяются по профилю пациента **детерминированно, без LLM**:

| Противопоказание | Поле профиля пациента |
|---|---|
| Гиперчувствительность к компонентам | аллергии |
| **Эпилепсия и органические заболевания головного мозга** | неврологический анамнез |
| **Одновременный приём иМАО и 2 нед после отмены** | текущая терапия |
| **Почечная недостаточность, СКФ < 60 мл/мин** | СКФ / креатинин |
| **Печеночная недостаточность, Чайлд-Пью A/B/C** | печёночные пробы, класс |
| **Беременность** | статус |
| **Период кормления грудью** | статус |
| **Возраст < 18 лет** | дата рождения |
| Непереносимость галактозы / дефицит лактазы | анамнез (лактоза в составе) |

Девять правил из одного документа. Это лучший аргумент в пользу метрики 10 («правила —
данные, а не код»).

## Режим дозирования

- 20 мг (1 таб.) 2 раза в сутки, утром и вечером, **за 30 мин до еды**, не разжёвывая.
- GAD: длительность определяет врач (хроническое течение).
- Пост-COVID тревога: курс **4 недели**, при необходимости до **6 недель**.
- Отмена: **постепенное снижение дозы не требуется**.
- Пропуск дозы: принять обычную дозу в следующий приём, пропущенную не добирать.
- Пожилые ≥65: коррекция не требуется.

## Нежелательные реакции (для функции 3 и для алертинга)

**Часто:** головная боль, головокружение, сонливость, парестезия, астения.
(Головокружение, сонливость, астения — в начале лечения, проходят сами.)

**Нечасто, но значимо:**

- Психические: инсомния, **усиление тревоги**, низкое качество сна.
- Нервная система: нарушение внимания, сниженная реакция на раздражители, дисгевзия.
- ЖКТ: тошнота, боль в верхней части живота, запор.
- Кожа: гипергидроз.
- Костно-мышечная: скованность мышц, **тризм**, боль в спине.
- Лабораторные: **повышение КФК**, **снижение гемоглобина**.

Три последних — кандидаты в «критическое состояние»: ↑КФК и тризм — сигналы
рабдомиолиза/серотониновой токсичности, ↓Hb — гематологическое НЯ.

## Взаимодействия → правила

| Взаимодействие | Эффект | Действие системы |
|---|---|---|
| **иМАО** | противопоказано | Блокирующий алерт |
| **Серотонинергические**: СИОЗС, СИОЗСН, ТЦА, литий, трамадол, триптаны, L-триптофан, фентанил, зверобой | риск **серотонинового синдрома** | Алерт «обязательно проверить» |
| **Седативные**: бензодиазепины, нейролептики, барбитураты, блокаторы H1 | усиление седации | Предупреждение |
| **Алкоголь / этанолсодержащие** | усиление угнетения ЦНС | Предупреждение пациенту |
| **Ингибиторы CYP2D6**: дифенгидрамин, тербинафин, хинидин, гидроксихлорохин, СИОЗС | ↑ концентрации Авиандра | Предупреждение |
| Дулоксетин (в КИ) | значимых изменений ФК нет | Справочно |
| Метопролол (субстрат CYP2D6) | значимых изменений нет | Справочно |

Отдельно: медленные метаболизаторы CYP2D6 — концентрация в 1,5–2 раза выше.

## Особые указания (для текста предупреждений)

- Осторожно при ССЗ (данных мало); QT не удлиняет.
- Может вызывать головокружение и сонливость → **не управлять транспортом**.
- Лекарственная зависимость и синдром отмены в КИ не выявлены, но теоретически возможны.
- Передозировка: антидота нет, лечение симптоматическое.
