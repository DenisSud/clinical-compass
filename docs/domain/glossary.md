# Глоссарий

Термины, которые в команде используются неточно. Фиксируем значения.

| Термин | Значение у нас | Не путать с |
|---|---|---|
| **CDSS** | Clinical Decision Support System — инструмент поддержки принятия врачебных решений. Подсказывает, решает врач | Автодиагностика, автолечение |
| **Тревожно-депрессивная симптоматика** | Сочетание тревожных и депрессивных симптомов. Не диагноз. Диагнозов минимум два: GAD и депрессивный эпизод | «Тревожная депрессия» как нозология |
| **GAD** | Генерализованное тревожное расстройство (МКБ-10 F41.1) — единственное тревожное показание Авиандра | Паническое расстройство, социальная фобия |
| **Авиандр** | Торговое название, МНН **маритупирдин**. Небензодиазепиновый анксиолитик. Показан при GAD и пост-COVID тревоге. **Не антидепрессант** | Антидепрессант, «препарат от депрессии» |
| **Маршрутизация** | Определение, куда направить пациента: остаётся у терапевта / к психиатру. С приоритетом «обязательно» или «желательно» | Направление (как документ) |
| **Алерт** | Автоматически порождённое системой уведомление врача о критическом состоянии. Не то же, что «напоминание» пациенту | Уведомление, напоминание, пуш |
| **Attention** (в mockup) | Флаг «этот опросник требует отдельного разбора». Сейчас единственный триггер — 9-й пункт PHQ-9 | Алерт (нет доставки, нет приоритета) |
| **Приверженность** | Adherence: принимает ли пациент препарат и следует ли рекомендациям | Комплаенс (устаревший термин) |
| **Шкала, self-report** | Заполняет пациент сам (PHQ-9, HADS, BDI, HCL-33) | Клиническая шкала |
| **Шкала, clinician-rated** | Заполняет врач на приёме (HAM-D, C-SSRS) | Самоопросник |
| **Валидация шкалы** | Психометрическое исследование, подтверждающее свойства инструмента на данной популяции и языке. Требуется ссылка | Просто «перевод на русский» |
| **ГРЛС** | Государственный реестр лекарственных средств. Источник официальных инструкций | РЛС (справочник, не реестр) |
| **Клинрекомендации** | Действующие, одобренные Минздравом России | Международные гайдлайны (допустимы как дополнение) |
| **НЯ** | Нежелательное явление | Побочный эффект (в инструкции — «нежелательная реакция») |
| **RAG** | Retrieval-Augmented Generation — генерация с опорой на найденные фрагменты источников. У нас: каждое утверждение со ссылкой на `KnowledgePassage` | Fine-tuning, «модель знает» |
| **Фрагмент (passage)** | Кусок текста источника с точными индексами `start`/`end` и sha256. Единица цитирования | Чанк (в mockup термин — passage) |
| **Офф-лейбл** | Применение вне зарегистрированных показаний/доз. Решение принимает только врач, система не предлагает | Экспериментальное лечение |
| **152-ФЗ** | Закон о персональных данных. Медицинские данные — специальная категория, повышенные требования | — |
