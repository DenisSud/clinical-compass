# Замеры: движок вопросов и генеративная модель

Короткая записка о том, что и как замеряется. Числа ниже получены на этой машине
(`npm run bench`), они не переносятся на другой сервер как обещание.

## Что сравниваем

Одна и та же задача: по данным пациента ответить на вопросы из `content/decisions/` —
«да», «нет» или «отказ». Два исполнителя:

- **движок вопросов** — `server/decisions/runner.ts`, чистые функции, файлы условий;
- **генеративная модель** — любой OpenAI-совместимый `/chat/completions`, ответ тем же
  JSON. Модель не имеет доступа к базе: ей дают те же три числа, что и движку.

Случаев 24 (`tools/bench/decisions-cases.json`): порог ровно на границе, рост меньше
порога, ноль пропусков, один пропуск, много пропусков без роста, нет прошлой отправки,
нет отметок приёма, обе величины отсутствуют. У каждого случая записан ожидаемый ответ.

## Технические замеры

| Что | Значение |
|---|---|
| Случаев в прогоне | 24 |
| Совпало с ожиданием | 24 из 24 |
| Отказов (данных не хватает) | 5 |
| Время на весь прогон | 164 мкс |
| Среднее на случай | 6.8 мкс |
| p50 / p95 | 6.7 / 10.5 мкс |
| Повторяемость | ответ побайтово тот же при повторе |

Прогрев идёт до замера: первый вызов разбирает файлы вопросов, и без прогрева он
попадал бы в p95 как «медленный случай», которого нет.

## Генеративная модель

Прогон возможен, когда заданы `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`:

```
LLM_BASE_URL=https://… LLM_API_KEY=… LLM_MODEL=… npm run bench
```

Без этих переменных печатается «не настроена», и это честный результат: сравнение
без модели не проводится. Модель отвечает по одному случаю за запрос, `temperature: 0`,
поэтому замер включает сеть и её задержку, а не только вычисление.

## Что эти числа значат и чего не значат

- Движок отвечает за микросекунды и повторяется побайтово: один и тот же пациент даёт
  один и тот же ответ, и это можно проверить.
- Модель сравнивается по тем же случаям, но её ответ недетерминирован по природе;
  совпадение с ожиданием — это согласие с нашими порогами, а не клиническая истина.
- Пороги и источники вопросов сейчас `placeholder` (материалы Антона не пришли).
  Замер проверяет поведение контура, а не правильность порогов (SPEC S30).
- Отказ — засчитанный ответ. Случай, где данных нет, движок обязан не отвечать «нет»
  (SPEC S27, Q36), и такие случаи в наборе есть отдельно.

## Как повторить

```
npm run bench                 # движок; про модель — сообщение, что не настроена
npm run bench -- /tmp/b.json  # то же плюс JSON с числами
npm test                      # набор случаев проверяется тестом, чтобы не разъехался
```
