# Как запустить demo

Всё через devenv, ничего устанавливать руками не нужно.

```bash
cd ~/dev/clinical-compass
devenv shell            # или `direnv allow` один раз
compass-mockup          # поднимает demo на http://127.0.0.1:8010/
compass-mockup-reset    # то же, но с чистой БД (пересоздаёт seed)
```

Порт по умолчанию 8010 (8000 обычно занят). Переопределяется:

```bash
COMPASS_PORT=9000 compass-mockup
```

## Учётные записи

| Роль | Логин | Пароль |
|---|---|---|
| Врач | `doctor_demo` | `CompassDemo!2026` |
| Пациент | `patient_demo` | `CompassDemo!2026` |

Есть ещё `doctor_other`, `patient_other`, `patient_new` — для проверки того, что один
врач не видит пациентов другого.

## Что смотреть

Проверено 20.10.2026:

1. `GET /` без сессии → редирект на `/login/`.
2. Логин врачом → `/doctor/` отдаёт 200, заголовок «Пациенты под наблюдением»,
   карточки «Активные связи», «Новые самоотчёты», «Ожидают ответа».
3. `/health/` → `{"status":"ok","version":"0.3.0","clinical_engine":"disabled","assessment_module":"demo_only"}`

Обратите внимание на `"clinical_engine": "disabled"` в `/health/` — это честный статус:
ИИ в mockup нет.

## Обход demo

### Как врач

1. `/doctor/` — список пациентов. Ищите панель «Ответы, требующие отдельного разбора»
   (это единственный зачаток алертинга).
2. `/doctor/invitations/` — создание одноразового кода приглашения (хешируется,
   TTL 48 ч).
3. Карточка пациента `/doctor/patients/<uuid>/` — сводка: опросники, график
   самочувствия, дневник, обращения.
4. `/doctor/sources/` — реестр источников. Тут видно `review_status: unverified` и
   `usage_rights` — заготовка под «научную обоснованность».
5. `/doctor/audit/` — append-only журнал.

### Как пациент

1. `/patient/` — кабинет. До подключения к врачу отправка заблокирована.
2. `/patient/connect/` — ввод кода приглашения.
3. `/patient/report/` — самоотчёт: шкала самочувствия 1–10 + заметка.
4. `/patient/assessment/phq9/` — PHQ-9. Ответ на 9-й пункт > 0 порождает `attention`.
5. `/patient/request/` — обращение к врачу асинхронно, без чата.

## Чего в demo нет

- ИИ: ни RAG, ни генерации, ни правил.
- Авиандра: нет ни препаратов, ни назначений, ни плана лечения.
- Маршрутизации к психиатру.
- Приверженности.
- Шкал кроме PHQ-9.
- Доставки алертов: `attention` — это только флаг в БД, уведомления нет.
