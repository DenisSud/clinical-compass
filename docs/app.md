# Приложение: два клиента, один модуль

Первый вертикальный срез (D14). Работает от экрана до строки в базе: пациент
отвечает на анкеты и видит свои приёмы, врач видит список пациентов, карточку с
динамикой и приёмы. Языковой модели здесь нет вообще.

## Запуск

```bash
make web          # пересоздаёт демо-данные и поднимает :8030
scripts/web.sh start   # без пересоздания данных
scripts/web.sh stop
```

Врач: `doctor@clinic.ru` / `compass`. Пациент входит по одноразовой ссылке —
`make seed` печатает шесть ссылок.

## Что на экранах

Врач:

| Экран | Что показывает |
|---|---|
| Пациенты | одна строка на пациента: дневник, последний PHQ-9 с полосой, последняя отметка, следующий приём, одна причина внимания |
| Карточка | находки по данным, график дневной отметки, все ответы, приёмы, форма записи на приём |
| Приёмы | все запланированные, с причиной внимания по каждому пациенту |

Пациент:

| Экран | Что показывает |
|---|---|
| Сегодня | ближайший приём, что подошло по сроку, последние отправки |
| Анкета | вопросы инструмента, по одному решению на пункт |
| Мои записи | приёмы и факты отправки — без баллов и полос |

## Откуда берутся выводы

Всё, что видит врач как «находку», — арифметика, а не модель. Два источника:

1. **Шкала.** `compass/instruments` считает сумму и полосу из JSON-определения.
   Полоса — опубликованное значение инструмента, ссылка на неё в карточке есть.
2. **Правило над рядом** (`compass/insights`). Изменение на 5 баллов, устаревание
   данных, доля заполненных дней, неполный ответ.

Каждая находка несёт `source`. Где число наше, а не из руководства, там так и
написано: «наш порог 5 баллов, не из руководства». Это не формальность — на
защите первый вопрос будет «откуда порог», и врать про источник нельзя.

Сигналы безопасности (пункт 9, мысли навредить себе) идут отдельной осью
(`compass/ai/triage`) и стоят в панели выше любых полос: балл описывает
состояние, а сообщение о самоповреждении описывает событие.

## Что здесь намеренно не сделано

- **Ни одного вызова модели.** По требованию: сначала исчерпываем
  детерминированные выводы (D13).
- **Приём как сущность с подписью.** `commit_appointment` и `publish` написаны и
  покрыты тестами, но не подключены к экранам — это срез 3.
- **Каталог препаратов.** `Catalog` в сборке отказывает на любом назначении,
  чтобы непроверенная доза не попала в код.
- **Планировщик.** «Что положено сегодня» считается на чтении из `cadences.json`,
  демона нет.
- **Параллельная запись.** SQLite сериализует писателей (D11).

## Как проверить, что это работает

```bash
devenv shell -- python -m pytest -m "not live" -q   # 114 тестов
```

Тесты ходят через HTTP и проверяют в том числе, что пациентская страница не
содержит ни балла, ни полосы, ни слова «балл» (D5), а чужую анкету отправить
нельзя.
