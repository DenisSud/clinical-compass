# Корпус знаний

Здесь лежат тексты, на которые опираются рекомендации. Один файл — один документ.
Пока каталог пуст, рекомендации не строятся: система говорит, чего не хватает,
вместо того чтобы придумать основание.

## Формат

`sertraline-smpc.json`:

```json
{
  "kind": "smpc",
  "id": "sertraline-smpc",
  "title": "Сертралин, ОХЛП",
  "inn": "сертралин",
  "tradeNames": ["Сертралин", "Золофт"],
  "source": {
    "publisher": "Реестр ЕАЭС",
    "url": "https://lk.regmed.ru/...",
    "retrievedAt": "2026-10-23"
  },
  "sections": {
    "indications": "…",
    "contraindications": "…",
    "dosing": "…",
    "interactions": "…",
    "warnings": "…"
  }
}
```

Для клинических рекомендаций `kind: "guideline"`, `inn` не нужен, а разделы —
`recommendations`, `firstLine`, `referral`.

## Правила

- Текст копируется из документа, а не пересказывается: карточка цитирует основание.
- `source.url` обязателен. Без ссылки документ не считается источником.
- Названия препаратов — в той форме, что в документе. Каноническое написание
  «Авиандр» ещё не подтверждено (issue #3), поэтому в карточку идёт то, что в ОХЛП.
