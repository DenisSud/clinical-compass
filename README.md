# Клинический компас — команда 6-И

Кейс-чемпионат: цифровой ассистент врача для ведения пациента с тревожно-депрессивной
симптоматикой. Партнёр — ГК ХимРар / ООО «Авинейро», препарат-якорь — Авиандр®
(маритупирдин).

Сдача: презентация по Zoom → исходный код на ревью → финал очно. Ориентир — конец
октября 2026.

## Быстрый старт

```bash
cd ~/dev/clinical-compass
direnv allow              # или: devenv shell

make verify               # 30 офлайн-тестов + корпус + шкалы
make doctor               # какие локальные модели доступны
make mockup               # demo от Антона на http://127.0.0.1:8010/
```

Учётные записи demo: `doctor_demo` / `patient_demo`, пароль `CompassDemo!2026`.

```

```

## Три вещи, которые определяют проект

1. **Кейс требует не ИИ, а обоснованности.** Каждое утверждение системы должно
   иметь ссылку на фрагмент клинрекомендации или инструкции. ИИ здесь — способ
   найти и сформулировать, а не способ решить.
2. **Mockup от Антона — клинический контур без ИИ.** Роли, аудит, приглашения,
   версионирование шкал, идемпотентность сделаны хорошо. Отсутствует ровно «мозг».
3. **Авиандр показан только при GAD, не при депрессии.** Тревожно-депрессивная
   симптоматика = два компонента и, возможно, два препарата. Комбинация
   Авиандр + СИОЗС даёт риск серотонинового синдрома — встроенный источник
   «предупреждений о безопасности терапии», которых требует кейс.

## Принцип, зашитый в код

**Модель может повысить внимание. Понизить — никогда.**

Находки из шкал авторитетны. Ответы `d1` — подозрение с указанием уверенности.
Инвариант в `compass_ai/triage.py::merge`, покрыт тестом.
