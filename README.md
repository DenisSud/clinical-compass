# Клинический компас — команда 6-И

Кейс-чемпионат: цифровой ассистент врача для ведения пациента с
тревожно-депрессивной симптоматикой. Партнёр — ГК ХимРар / ООО «Авинейро»,
препарат-якорь — Авиандр® (маритупирдин).

Сдача: презентация по Zoom → исходный код на ревью → финал очно. Конец октября 2026.

## Быстрый старт

```bash
cd ~/dev/clinical-compass
direnv allow           # или: devenv shell
make verify            # 30 офлайн-тестов
make doctor            # какие локальные модели доступны
make mockup            # demo от Антона на http://127.0.0.1:8010/
```

## Структура

```
compass/               один пакет, три модуля
  instruments/         шкалы: определения (JSON), подсчёт, сигналы безопасности
  knowledge/           корпус: документы, цитируемые фрагменты, смещения
  ai/                  модели: Assistant Protocol, триаж, поиск, черновики
docs/                  знания о кейсе, клинике, команде, решениях
reference/mockup/      mockup от Антона, вендорен как есть
tests/                 30 офлайн + 7 живых
```

Направление зависимостей — в одну сторону:

```
instruments  ─┐
              ├─→  ai
knowledge    ─┘
```

`instruments` и `knowledge` импортируют только стандартную библиотеку. Это
намеренно: подсчёт шкалы должен доказываться тестом без модели, без БД и без сети.

## Три вещи, которые определяют проект

1. **Кейс требует не ИИ, а обоснованности.** Каждое утверждение системы имеет
   ссылку на фрагмент клинрекомендации или инструкции. ИИ здесь — способ найти и
   сформулировать, не способ решить.
2. **Mockup от Антона — клинический контур без ИИ.** Роли, аудит, приглашения,
   версионирование шкал, идемпотентность сделаны хорошо. Отсутствует ровно «мозг».
3. **Авиандр показан при GAD, не при депрессии.** Тревожно-депрессивная
   симптоматика = два компонента, возможно два препарата. Комбинация
   Авиандр + СИОЗС даёт риск серотонинового синдрома — встроенный источник
   «предупреждений о безопасности терапии», которых требует кейс.

## Принцип, зашитый в код

**Модель может повысить внимание. Понизить — никогда.**

Находки шкал авторитетны. Ответы `d1` — подозрение с указанной уверенностью.
Инвариант живёт в `compass/ai/triage.py::merge`, покрыт тестом.

## Demo (mockup Антона)

```bash
compass-mockup          # :8010, БД сохраняется
compass-mockup-reset    # то же с чистой БД
COMPASS_PORT=9000 compass-mockup
```

| Роль | Логин | Пароль |
|---|---|---|
| Врач | `doctor_demo` | `CompassDemo!2026` |
| Пациент | `patient_demo` | `CompassDemo!2026` |

Ещё есть `doctor_other`, `patient_other`, `patient_new` — чтобы проверить, что
один врач не видит пациентов другого.

Обход как врач: `/doctor/` (панель «Требуют разбора») → `/doctor/invitations/`
(одноразовый код, TTL 48 ч) → карточка пациента → `/doctor/sources/`
(`review_status: unverified`) → `/doctor/audit/` (append-only).
Как пациент: `/patient/connect/` (код) → `/patient/report/` → `/patient/assessment/phq9/`
(ответ на пункт 9 > 0 порождает `attention`).

`GET /health/` отдаёт `{"clinical_engine": "disabled", "assessment_module": "demo_only"}` —
честный статус: ИИ в mockup нет.
